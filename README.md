# Shree Shyam Tiles & Granite — Android App V1

Flutter starter app for a tiles & granite inventory/price manager.

## V1 included
- Dashboard
- Product/stock list
- Product search
- Add Product
- Our Price / Selling Price list
- Local persistence using SharedPreferences
- Low-stock count
- Demo products for testing

## Next modules
Purchase, Sales/Bill, Customers, Suppliers, Reports, GST invoice, backup/restore, product images, barcode and cloud sync.

## Run
1. Install Flutter SDK and Android Studio.
2. From this folder run `flutter pub get`.
3. Connect an Android phone with USB debugging enabled or start an Android emulator.
4. Run `flutter run`.
5. For APK: `flutter build apk --release`.
